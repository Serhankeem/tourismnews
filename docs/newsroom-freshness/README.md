## 원인과 수정 범위

1. 서버 `project()`는 발행일 내림차순 정렬 뒤 editorial rank로 재정렬하여 오래된 국내 직접 관련 기사를 앞세웠습니다. 문자열 정렬은 시간대가 다른 동일 시각도 잘못 비교할 수 있었습니다.
2. 브라우저는 editorial이 없는 공개 6필드 JSON을 서버 순서 그대로 표시했습니다. legacy editorial이 있는 경우에도 rank 재정렬을 반복했습니다. 홈페이지는 그 배열의 앞 3개를 그대로 사용했습니다.
3. 브리핑은 최근 24시간·검증된 시각·한국 직접 관련/세계 산업 주요 변화 조건을 적용했지만, 최근 3건 모두 reference로 분류됐습니다. 빈 결과를 모두 `no_recent_articles`로 기록하여 ‘기사 없음’과 ‘편집 기준 미충족’을 혼동했습니다.

서버와 브라우저 모두 원문 발행 **시각** 내림차순으로 변경했습니다. 동일 시각은 원문 URL(서버 내부의 같은 URL이면 ID)로 결정하며 입력 배열을 뒤집어도 동일합니다. editorial은 저장·브리핑 기준으로 유지하고 기본 뉴스 순서에는 사용하지 않습니다. 발행 문자열·시간대·정밀도는 변경하지 않았습니다. 날짜만 있는 항목은 정렬에만 KST 해당 일의 하한을 사용하고 24시간 브리핑에서는 제외합니다. 유효하지 않거나 명시적으로 미검증인 시각은 마지막에 둡니다. 공개 데이터는 기존 승인된 메타데이터의 순서만 재투영했습니다. 신규 수집/발행일 변경/가상 기사 추가는 없습니다.

## 브리핑 상태 / 아카이브 정책

- `no_recent_articles`: 검증된 최근 24시간 발행 뉴스가 0건.
- `no_eligible_recent_articles`: 최근 발행 뉴스는 있으나 편집 등 선정 기준 미충족.
- `candidates_ready`: 적격 후보가 있음(최대 5건).
- `collection.status=partial/failed`: 위 선정 결과와 독립적으로 후보 공급의 불완전함을 표시. 성공/실패 출처 수도 보관.
- `health.briefing.status=failed`: 생성/쓰기 실패를 기록하고 마지막 공개 후보 보존. 엔진 CLI도 실패 종료하여 기존 Actions 오류 흐름에서 확인 가능. 브라우저 HTTP/검증 실패도 빈 후보와 구분. 예외 원문은 공개하지 않음.
- 오래된 후보는 생성 시각과 갱신 지연을 표시합니다. 전체 수집 실패 시 기존 공개 파일 보존 정책도 그대로입니다.

10:30 이후 첫 성공 실행에 빈 후보를 확정하는 기존 정책은 일일 소식 탐색에 불리합니다. 실제 11월 2일 확정본 생성은 11:20:47 KST, 0건이며 이후 적격 후보가 있어도 덮어쓰지 않습니다. 이번 PR은 **기존 날짜별 확정본을 재작성하지 않고** ‘현재 후보’를 갱신하며 빈 확정본 화면에서 현재 후보 확인을 안내합니다. 아카이브 4일치와 내부 확정 선정 이력은 바이트 동일합니다.

SEC의 과거 `robots_unverified:http_403`은 robots 응답을 확인할 수 없어 자동 중단한 결과이지 본문/피드 접근을 시도해 우회했다는 뜻이 아닙니다. 이번 robots 확인과 공식 JSON 호출은 정상입니다. 일시적 차단/중간망 응답 가능성은 있으나 과거 403 발생 주체는 확정할 수 없습니다.

문체부와 KOSIS 재시도는 robots 503입니다. 추가 HEAD 확인도 TLS 성공 후 HTTP 503(`server: envoy`)이며 명시적 네트워크 정책 거부 헤더는 관측하지 못했습니다. 프록시 진단 보존 기록도 없어 원본과 중간망 중 응답 주체는 미확인입니다. TLS 미지원으로 단정하지 않습니다. KOSIS의 직전 `https_public_endpoint_required`는 보호 로더가 HTTPS가 아닌 대상/리디렉션을 거절한 것이며 이 제한을 해제하지 않았습니다. 두 출처는 이후 정상 실행에서 재확인해야 합니다.

현재 robots/이용조건상 **명시적 금지로 새로 확인된 출처는 없고**, 미검증 robots 응답에서는 접근을 중단했습니다. 폐기·지원 종료가 확인된 피드도 없습니다. 재시도·원본 운영 상태 확인이 우선이며 403만으로 ‘종료된 피드’라고 기록하지 않습니다. 이용조건·수집원 설정·계약 승인 범위는 변경하지 않았습니다. 18개 대상의 구조화 관측은 [source-probes.json](source-probes.json)에 있습니다.
