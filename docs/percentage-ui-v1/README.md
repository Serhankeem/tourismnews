## 표시 규칙

| 입력 | 표시 | 상태/색상 |
| --- | --- | --- |
| `21.1`, `"+21.10%"` | ▲ +21.10% | 양수 `#C8434D` |
| `-8.4`, `" -8.40% "` | ▼ -8.40% | 음수 `#2864AD` |
| `0`, `-0`, `"-0.00%"` | — 0.00% | 보합 `#718096` |
| `null`, 빈 문자열, `NaN`, 미연동, 잘못된 값 | — | 증감 컬러 미적용 |

숫자 자체로 방향을 판정한 뒤 기존 `toFixed(2)`를 적용합니다. 예를 들어 실제 값 `-0.001`은 0이 아니므로 `▼ -0.00%`입니다. 정확한 0과 음의 0은 보합입니다. `1.235`는 기존과 같이 `+1.24%`로 반올림합니다.

문자열은 올바른 쉼표 묶음, 부호, 부호 뒤 공백, 소수점, 선택적인 `%`만 허용합니다. `1,23%`, `1 2%`, 지수/16진수 문자열, 중복 부호, HTML은 결측으로 처리하며 0으로 바꾸지 않습니다. 실제 숫자 타입의 유한값은 그대로 사용합니다. 사용자 문자열을 HTML에 넣지 않고 고정된 클래스·방향과 검증된 숫자 출력만 삽입합니다. 아이콘 외에도 스크린리더용 증가/감소/보합 설명을 제공합니다. 결측은 `aria-label="비교 자료 없음"`입니다.

## 검증

- Python 전체: **481개 통과**. `tests/test_percentage_ui.py`가 기존 Python CI 진입점에서 Node 공통 표시 단위 테스트도 실행합니다.
- 브라우저: **20개 전체 스위트 통과**. [스위트별 결과](browser-results.json), [검증 요약](test-results.json).
- 새 브라우저 테스트: 320·390·768·1440px, 실제 데이터 불변, 양수/음수/보합의 정확한 RGB, 결측/XSS, 국적별/홈/Macro/월별 비교/Data Observation 일관성, 실적 차트 색상 유지, 기존 증감률 차트 색상, SVG 툴팁, 카드·문서 넘침, 시뮬레이션 점수 불변.
- 원래 브라우저 테스트 19개도 실행했습니다. 결측 문구의 기존 검사는 요청한 `—` 표시와 접근성 설명 검증으로 갱신했습니다.
- `newsroom-freshness.smoke.cjs`는 수정 전 main에서도 24시간이 지난 스냅샷을 최신 후보로 가정해 실패했습니다. 테스트의 시각만 실제 스냅샷 생성 시각으로 고정하고, 추가로 25시간 경과 문구도 검증했습니다. 운영 브리핑 로직·데이터는 그대로입니다.
- GitHub CI 최종 결과는 이 PR의 Checks에서 확인할 수 있습니다. 수집/게시 job은 기존 main 전용 조건을 유지합니다. 이번 작업에서 운영 수집이나 Pages 배포를 실행하지 않습니다.

## 데이터·기능 보존

동일한 운영 스냅샷을 기존 파이프라인의 게시 게이트와 compose로 main/변경 코드 각각에 로컬 결합했습니다. **배포용 JSON 12개와 내부 원장을 포함한 30개 파일이 바이트 단위로 동일**합니다. 보호 대상 코드·설정·로고 91개도 main과 동일합니다. [SHA-256 보존 증거](preservation.json).

`src/`, 수집 설정, `macro_sources.json`, `sources.json`, `collector_state`, 운영 JSON, `data/live`, GitHub Actions, 로고 원본, 뉴스/리서치/브리핑/통계 원장과 승인 게이트는 수정하지 않았습니다. 외부 API·인증키를 사용하거나 ECOS를 활성화하지 않았습니다.

테스트 경계값은 단위 테스트 또는 브라우저 메모리에만 존재합니다. 아래 스크린샷은 경계값 주입 전에 실제 공개 스냅샷으로 촬영했으며 미연동 관광수입·지출 카드도 그대로입니다. 이 PR은 통계 실연동이나 데이터 최신성을 개선한 것으로 보고하지 않습니다.
