## 목적과 방법

기존 ECOS Candidate Comparison은 301Y013과 301Y014의 최근 12개월 수입/지급 24개 값이 동일함을 확인했습니다. 이번 작업은 **그와 별도로**, 사용자가 제출한 CSV의 표시값과 공식 ECOS 301Y013 값을 비교합니다.

- 원본 CSV와 원시 금액을 저장소에 넣지 않습니다.
- `kto-provisional-digests.json`에는 월별 수입·지출 표시값에서 만든 SHA-256 지문만 포함합니다.
- 통계수치의 범위가 좁아 지문은 역추정될 수 있습니다. **비밀 데이터의 익명화 수단이 아닙니다.**
- 공식 ECOS 메타데이터에서 301Y013 일반여행수입 `2C1Y00`, 일반여행지급 `2C2Y00`, 단위와 기간을 재검증합니다.
- StatisticSearch를 통해 각 12개월 수치를 메모리 내에서 조회하고 Decimal `ROUND_HALF_UP` 기준 소수점 첫째 자리로 반올림하여 지문을 대조합니다.
- 공개 Summary는 월별 `matches_at_one_decimal`, `different_at_one_decimal`, `missing`만 표시합니다. 수치, 인증키, 원시 API 응답이나 인증 URL은 공개하지 않습니다.
- 비교값이 모두 같더라도 공식 KTO 출처, 재공표, 빈티지, 이용약관 및 운영 승인은 **검토중**입니다.

## 실행

1. PR을 검토·병합합니다. 다른 기존 GitHub Actions의 main push 트리거에 따른 작업은 발생할 수 있습니다.
2. GitHub → Actions → **ECOS KTO Provisional Comparison** → Run workflow → Use workflow from **main** → Run workflow. 추가 입력은 없습니다.
3. Summary에서 12개월 × 수입/지급 = 24개 결과를 확인합니다.
4. 결과가 `24/24 matches_at_one_decimal`라도 승인·배포를 의미하지 않습니다.
