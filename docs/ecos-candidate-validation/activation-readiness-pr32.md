# PR #32: ECOS 운영 활성화 사전검증 — 301Y013

## 1. 현재까지 실증된 내용
- ECOS Preflight: 통계표 목록 844개, 월간 후보 6개 전수 검사, 일반여행수입/지급 후보 2쌍. 301Y013과 301Y014가 확인됨.
- ECOS Candidate Comparison: 2025-10~2026-09 월별 수입 12건·지급 12건 두 표의 값이 매월 일치.
- ECOS × KTO user CSV: 동일 기간 24/24개 표시값이 백만달러 소수점 첫째 자리에서 일치.
- 한계: KTO 파일 원본 출처·다운로드 URL·수록 기준(잠정/확정)·개별 공표일 미확정. 실제 ECOS 신규 정정 여부는 향후 재조회에서 별도 점검.
- 운영 설정은 source/indicator disabled이며 mapping, rights_review, crosscheck **절대 자동 승인하지 않음**.

## 2. 이번 PR의 책임 범위
- 수동 **ECOS Activation Readiness** workflow 추가 (`workflow_dispatch`, main-only, contents:read, ECOS_API_KEY Secret 단일 스텝).
- 실제 인증된 ECOS 통계표 목록(301Y013)과 항목 목록에서 공식 통계표 이름·주기 M·Group1 계층·수입/지급·단위·수록기간 재검증.
- 검증 통과한 **메모리 내 임시 mapping**을 기존 `src/macro/ecos.py`의 `mapping()` 및 `validate_metadata()` 계약에 대조.
- 금액을 조회하는 `StatisticSearch` **호출 금지**. `data/live`, 운영 JSON, GitHub Pages, 기타 수집기, 기존 Preflight 및 승인 가드 변경 금지.
- Actions Summary에 결과·코드·단위·기간만 기록. 원본 API 응답, 원본 명칭, 키 및 인증 URL 비출력.
- **운영 mapping 설정 파일의 상태를 pending에서 verified로 바꾸지 않음.** 재조회 결과와 공식 승인 증빙은 별도 PR에서만 반영.

## 3. 확인 가능한 공식 권리 근거
- 한국은행 공식 저작권보호방침: https://www.bok.or.kr/portal/main/contents.do?menuNo=200228
- 이 정책에 따르면 제공대상 공공데이터는 해당 범위에서 별도 절차 없이 이용할 수 있고, 목록에 포함되지 않은 정보를 링크 외의 방식으로 사용할 경우 사전 협의가 필요함.
- 또한 한국은행 정보를 이용하거나 수정·가공할 때 출처를 밝혀야 함.
- **301Y013 일반여행수입/지급이 해당 '제공대상 공공데이터' 범위에 포함되는지, ECOS 통계 이용지침의 계열별 조건이 무엇인지 아직 확정하지 못했음.**
- 근거 없는 제3자 API 소개나 외부 프로젝트의 이용방침으로 공식 승인 처리 금지.
- 승인 담당자에게 문의할 때 프로젝트 특성(학생·비영리 공개 대시보드), 제공할 필드(수치, 기준월, 단위, 출처, API 링크), 자동 갱신 및 가공(수입−지출)을 구체적으로 알리고 적합성을 확인해야 함.
- 한국은행 홈페이지 정책의 문의 창구는 저작권보호방침에 명시된 담당 부서 이용. 개인정보나 인증키를 공개 저장소에 게시하지 않음.

## 4. 실제 통계표 계층 검증
- 통계표 `301Y013` (국제수지 / 월간 M), 단위 `백만달러`
- 수입: `000000 경상수지 → 200000 서비스수지 → 2C0000 여행수지 → 2C1000 여행수입 → 2C1Y00 일반여행수입`
- 지급: `000000 경상수지 → 200000 서비스수지 → 2C0000 여행수지 → 2C2000 여행지급 → 2C2Y00 일반여행지급`
- 항목 명칭, 부모 코드, 계층, Group1 단위, 기간, 표 명칭이 하나라도 다르면 실패. 자동 매핑 추정이나 대체 통계표 사용 없음.
- 기존 어댑터의 **원본 통계표 이름·항목 이름 일치 요구**도 검증하도록 실제 Metadata를 다시 사용.
