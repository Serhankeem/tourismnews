## 통제 및 한계
- `macro_sources.json`에서는 TOURGO `approval.collection`만 기록하며, `approval.publication.approved=false`와 `source.enabled=false`를 유지한다.
- 관광수입·관광지출 지표도 `enabled=false`로 유지한다. `data/live`, News, Research, KTO, ECOS, 워크플로, Secrets, 보호 환경을 변경하지 않는다.
- 기존 `scope=general_travel_monthly` 필드 자체는 **2026-09까지만 수집하도록 기술적으로 강제하지 않는다**. 2026-10 이후 신규 월 수집은 별도의 범위 확인/통제 조치 전까지 진행하지 않는다.
