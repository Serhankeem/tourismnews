기준 main `bb2d47b1`(PR #63·#64 병합). 기존 수동 가정식은 제거하고 `MacroMonitor.database`의 검증된 공개 객체 하나로 홈/상세를 계산합니다. `#weather-simulator` URL은 유지하며 이름은 **관광시장 모델 · 공식 관측**입니다. 월간 진단 VOL.01의 원고·발행 파일·승인 방식과는 별개입니다.

## 버전에 고정한 산식

결과를 보기 전에 창 길이·균등가중·표시 구간을 고정했습니다. 실제 결과에 맞춰 조정하지 않았습니다.

1. `Y[t] = 100 × (X[t] / X[t−12] − 1)`.
2. `S[t] = (Y[t] + Y[t−1] + Y[t−2]) / 3`.
3. 참조는 `S[t−24] … S[t−1]`의 **연속 24개월**입니다. 목표월은 제외합니다.
4. 상대 위치 `P[t] = 100 × (참조값 중 더 낮은 수 + 동률 수/2) / 24`.
5. 부분 신호 `M[t] = 0.5 × P[방한] + 0.5 × P[일반여행수입]`.

정수 원값을 BigInt 유리수로 계산해 순위 비교 전에 반올림하지 않습니다. 성장률·기여도는 출력 6자리, 화면은 2자리로 표시합니다. 표시값을 다시 모델 입력으로 쓰지 않습니다.

| 미반올림 점수 | 아이콘 |
| --- | --- |
| 0 이상 25 미만 | 비 |
| 25 이상 50 미만 | 흐림 |
| 50 이상 75 미만 | 구름 조금 |
| 75 이상 100 이하 | 맑음 |

이는 고정 등간격 표시 규칙입니다. 실제 호황·침체 정답으로 학습/최적화한 임계값이나 성장 확률이 아닙니다. 원지표가 증가해도 과거 성장률보다 낮으면 낮은 신호가 나올 수 있습니다. 작은 정정이나 경계 부근의 가중치 선택은 날씨를 바꿀 수 있습니다.

## 입력·판정 유보

- 핵심은 `kto_inbound`와 `kto_tourism_receipts` 두 개만입니다. source ID·정의·월 주기·단위(명/US$)·publisher·연결/활성 상태·검증 방법·공식 출처를 고정 계약과 대조합니다. KTO는 공식 XLSX 검증/KOGL-0/파일 해시, TOURGO는 공식 파일 검증/수동 Excel 입력 경로를 확인합니다.
- TOURGO는 **2021-01~2026-09**를 넘지 않습니다. 기존 서버의 권리·수집/게시 게이트를 통과한 공개 Macro projection이 권리 경계입니다. 클라이언트가 비공개 계약을 재승인하거나 승인 기간을 확대하지 않습니다. 무료·비상업·출처 표시는 기존 사이트/운영 정책을 유지합니다.
- 목표월의 최신 두 계열이 일치해야 합니다. 비교에 필요한 **39개월 원값**(목표월−38 … 목표월)이 연속이어야 합니다. 이전 자료로 최신월을 몰래 대체하지 않습니다.
- 결측/중복/음수/안전 정수 초과, 0 분모, 단위/정의/출처/검증 불일치, latest와 원값/제공 YoY 불일치, 24개월 분포 전체 동일이면 판정을 유보합니다. 관측된 0인 분자는 실제 0으로 계산하되 누락을 0으로 채우지 않습니다.
- 완료된 월만 사용하며 현재 분석월(KST)보다 3개월 넘게 오래된 기준월은 유보합니다. 이 지연 한도도 v1.0.0 정책입니다. Macro 새 DB 확인 실패 시 이전 공식 카드 값은 유지해도 모델 점수/날씨는 유보합니다.
- 출국·일반여행지출·국적별 통계는 보조 관측입니다. 항공·고용·내국인 카드소비·ECOS는 입력에서 제외하며 0/추정으로 대체하지 않습니다.

일반여행수입은 국제수지 개념의 **명목 US$**이며 물가/환율 보정 실질소비가 아닙니다. 방한 통계는 공표 입국 기준으로 순수 관광목적/고유 방문자만을 뜻하지 않습니다. 두 모집단을 나눠 1인당 지출을 만들지 않습니다.

검사는 기존 공개 원장의 구조/정의/비교 일치와 서버 검증 상태를 사용합니다. 클라이언트가 원본 XLS를 독립 재파싱하거나, 수치와 메타데이터를 함께 조작한 제3자 파일의 진위를 암호학적으로 증명하지는 않습니다. 임의 JSON을 운영 원장으로 승인하는 기능이 아닙니다.

## 회고 검증과 한계

- 2021-01~2026-09 **69개 평가월** 중 31개월(2024-03~2026-09) 계산, 초기 38개월은 참조 이력 부족으로 유보. 계산월 점수 범위 2.083333~79.166667입니다.
- 각 평가월에 그 이후 월을 제거한 prefix와 결과를 대조합니다. 미래값 제외/범위 불변식 위반 **0건**. 감사 중 예외/불변식 실패도 `backtest_failed`로 유보합니다.
- 별도 Python `Fraction` 산식으로 성장률·평활값·순위·점수/아이콘을 **217회 독립 대조**했습니다. 운영 계산은 동일 브라우저 JS 모듈 하나이고 Python 산식은 검수 oracle뿐입니다.
- 연구용 40:60/60:40 가중치 민감도 62개 경우 중 **10개**가 표시 구간을 바꿨고 최대 점수 차이는 7.916667점입니다. 2026-09는 61.666667~63.333333점으로 같은 구간입니다. 운영 50:50을 바꾸지 않았습니다.
- 최신 원값의 각 계열 ±1 저장 단위 변동 4개 메모리 복사 스트레스는 모두 62.50점/동일 날씨였습니다. 이는 실제 정정 사건이 아니며 모든 규모의 정정에 안정적이라는 보증도 아닙니다. 일관된 정정은 결정적으로 재계산합니다.
- 계산된 31개월 중 24개월에는 참조에 팬데믹 시기 분모가 포함됩니다. 계절조정하지 않았고 YoY에도 기저/구조 변화가 남습니다. 3개월 평활과 두 핵심 계열은 상관될 수 있어 독립 신호의 수나 통계적 유의성을 뜻하지 않습니다. 24개 참조값도 겹치는 독립 표본 24개가 아닙니다.
- 전체 결과는 **retrospective_current_vintage**입니다. 미래 월을 쓰지 않는 회고 계산이지, 과거 당시 실제 공표 빈티지를 확보한 실시간 백테스트가 아닙니다. 예측 정확도/설명력의 인과 검증/공식 경기 판정은 주장하지 않습니다.
