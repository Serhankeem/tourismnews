## D. 분류·데이터 품질

- 기존8개 분야/공개8필드/공개 schema_version1 유지. DOI/검증 근거는 운영 원장에
  보존하고 기존 서지 UI·필터·출처 표시를 사용한다. KOGL 출처/저자는 기존
  attributions 구조를 KOTI에도 적용한다.
- MICE는 business events/international meetings/congress/exhibition industry와
  국제회의/전시산업 등 문맥 있는 용어를 사용한다. meeting/event/congress/
  convention 단독으로 확정하지 않는다.
- 영문 경계를 모든 용어에 적용해 `retail`을 `rail`로, 일반 문장을 MICE로
  오인하지 않는다. 한글 붙임말(MICE산업)은 허용한다. 숙박·객실·야영장·항공·여객
  용어를 보완했다. `Policies` 복수형도 관광정책으로 인식한다.
- 신규 OECD2건은 공식 원제목의 **Policies**를 근거로 정책 분야로 검토 정정했다.
  최초 자동 분류와 검토 이후 분류를 coverage.json 및 각 원장의 versions에 남겼다.
  기존110건의 공개 필드는 바꾸지 않았으며 총량/분야 할당을 위한 재분류가 아니다.
- 신규 날짜는 **연도19건 + 일 단위6건**. 등록일·수정일을 발행일로 변환하지 않았다.
  2023년처럼 연도만으로 36개월 범위에 확실히 들어온다고 할 수 없는 자료도 억지로
  포함하지 않는다. 기존 자료는 수집 창 밖으로 나가도 삭제하지 않는다.
- 접근 구분: 무료19→44, 유료11 유지, **미확인80 유지**. 미확인 유형 개선은 미달.
  새 무료25건을 기존80건의 접근유형 검증 성과로 계산하지 않는다.
- 새 코드는 동명 판의 메타데이터 변경(access/category 포함)도 이전 공개 필드를
  versions에 보존한다. 공식 URL/기관 문서ID/같은 판의 제목·발행일 중복을 제거하고
  다른 연도/분기는 합치지 않는다. 개정 관계가 없으면 임의로 개정판 연결하지 않는다.

  검색, MICE/항공/숙박, 날짜/저자/공공누리, 원문 링크, PC·모바일을 대조했다.
  기존 320~1440px 내비게이션/브리핑/관측/날씨/차트 회귀도 통과했다.
- PDF/XLSX/Office/이미지·아카이브 URL/MIME/magic 차단을 보강했다.
  보고서 본문/초록/목차/이미지를 공개하거나 분류·요약 입력으로 추출하지 않았으며,
  다운로드/미리보기 버튼을 실행하지 않았다. HTML 메타데이터 페이지 자체의 응답만 읽었다.
- UI 디자인/로고/뉴스·브리프/날씨/Data Observation/Macro/TOURGO 승인/Actions 파일은
  변경하지 않았다. Research 관련 JSON/설정/수집·분류·telemetry와 테스트만 변경했다.
- `git diff --check`와 Python syntax 통과. API 키·인증·비밀번호는 사용/추가하지 않았다.

## 남은 작업·사용자 승인 필요 사항

- 활성화한 OECD/KOTI에는 새 API 키가 필요 없다. 이번 범위의 외부 메시지 발송 없음.
- K-MICE/한국MICE협회는 개별 정식 발간물·서지 날짜·외부 메타데이터 색인·정상 자동
  경로를 확인해야 한다. 허용이 불명확해 요청/등록량을 늘리지 않는다.
- ICCA는 공개 플랫폼 서지 활용·자동 접근 범위의 기관 서면 허락이 필요하다.
  회원 계정이나 수동 등록으로 제한을 우회하지 않는다.
- 공항기관/항공포털/호텔협회는 허용된 RSS/API/서지 공급 경로 확인이 필요하다.
  KCTI403도 기관 안내와 정상 접근 회복을 확인할 과제로 남긴다.
- 150건과 미확인80건 개선은 달성하지 못했다. 추가 증가는 검증 가능한 자료가
  확보될 때 진행하며, 제목·권한·날짜 기준을 완화하지 않는다.
