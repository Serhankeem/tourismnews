# News Engine v0.5 — 국내 뉴스 커버리지 점검

## 결론과 측정 범위

**신규 국내 공개 공급원은 0곳이다. 국내 일일 공급망·매체 다양성 확보 문제는 미해결이다.** 기존 허용 전문매체에서 분류 누락 7건을 복구해 공개 뉴스 47→54건을 확보했다. 이는 공급원 2~3곳 확보 목표 달성이 아니다. SEC·해외 정부·공공기관 자료로 국내 공급 부족을 보충했다고 집계하지 않았다.

기준은 PR #17 병합 후 최신 main `54117f6`이다. 2026-11-03 실제 네트워크 응답을 수집했고, 기존 26개 피드 응답의 캡처 종료는 **15:13:02 KST**이다. 동일한 응답을 격리 실행/운영 파일 투영/재처리에 사용했다. 별도 재처리를 추가 네트워크 성공 횟수로 계산하지 않는다. 가상 기사를 공개 DB에 넣지 않았다. 이 결과는 한 차례 관측이며 지속 공급·운영 Actions 연속 성공을 증명하지 않는다.

PR #17의 [후보 검토](../newsroom-source-expansion-v04/candidate-review.json), [접근 기록](../newsroom-source-expansion-v04/access-observations.json), [최종 검토](../newsroom-source-expansion-v04/PR17-final-review.md), [공개 게이트](../newsroom-source-expansion-v04/PUBLICATION-GATE.md), README와 source-audit를 재사용했다. 46개 후보 전부를 재수집하거나 기존 보류를 해제하지 않았다.

같은 기준 시각의 비교다. ‘국내 발행처’는 명시적 KR 출처 설정이고, **한국 관광시장 직접 관련성은 별도 editorial 증거**이다. 국내 매체의 해외 보도를 국내 시장 직접 뉴스로 계산하지 않는다.

### 문화체육관광부 15개 기관 보도자료 API

[공식 등록 페이지](https://www.data.go.kr/data/15105015/openapi.do)는 robots 확인이 HTTP 503으로 실패했다. 문화포털의 공식 링크를 따라 [문화공공데이터광장](https://culture.go.kr/data/main/main.do) 및 공식 공지 경로도 확인했으나 HTTP 503으로 명세에 도달하지 못했다. 네트워크 정책은 unrestricted이며 이번 오류는 Loader가 받은 실제 HTTP 응답/전송 실패다. 이를 클라우드 허용 목록 차단이나 원 서버 자체 차단으로 단정할 근거는 없다.

| 검증 항목 | 결과 |
|---|---|
| 실제 서비스 API 주소·LINK 여부·호출 방법 | **미확인** (등록 페이지 URL을 API 주소로 사용하지 않음) |
| 인증키·무료/유료·호출 제한 | **미확인** |
| 관광기관 필터·원 발표기관 식별 | **미확인** |
| 제목·원 발행일·직접 링크 필드 | **미확인** (등록일을 발행일로 추정 안 함) |
| 최신 기준일·최근 7일 자료량 | **미측정** |
| 데이터셋 이용허락·개별 저작물 조건 | **미확인** |
| 활성 연결·공개 게시 | **없음 / 0건** |

등록 사실은 사용자 제공 정보이며 현재 정상 운영의 실증이 아니다. 엔드포인트·응답 필드를 추측한 어댑터나 키 없는 가짜 성공 처리는 구현하지 않았다. 명세와 권한이 확보되면 원 발표기관 허용 목록, 실제 발행시각 검증, 개별 이용조건 및 기존 PublicationGate를 거쳐 연결해야 한다.

### 뉴스와이어 API

[제휴 안내](https://www.newswire.co.kr/coalition), [약관](https://www.newswire.co.kr/coalition/policyterms), [공식 API 문서](https://www.newswire.co.kr/coalition/document), [RSS 안내](https://www.newswire.co.kr/?md=A31)는 이번 HTTPS 접근 성공이다.

- 신청 → 내부 심사 → 승인 후 키 발급. 약관 이용자는 법인·기관·단체로 정의되어 **개인 비상업 프로젝트의 신청 자격은 미확인**이다.
- 승인된 웹사이트/CMS 등 목적별 활용을 안내한다. 무료·무광고라는 이유만으로 공개 허가가 있다고 보지 않는다. 비용·무료 가능 여부·계약 쿼터는 **미확인**이다.
- 공식 문서는 `POST https://www.newswire.co.kr/api/v1/request` → `/api/v1/send` → 수신 결과 확인 절차, `partner_id`, `X-HMAC`(발급 키 기반), `X-Timestamp`를 요구한다. **운영 API를 호출하지 않았다.**
- 문서상 수신당 최대 100건, 장기 미수신 과거 최대 1,000건, 5~10분 수신 간격 안내가 있다. 이는 계약상 호출 쿼터/무료 제공 확약이 아니다.
- RSS 안내에 여행·호텔·항공 분야가 있으나 계약 API의 관광 분야 필터·전송 범위는 별도 확인해야 한다. 소비자 RSS 구독 안내를 공개 사이트 허가로 해석하지 않는다.
- 약관은 출처 오인·무단 재판매/경쟁 제공·제한 우회를 금지한다. 제7조는 정정·삭제 통보의 즉시 DB 반영을 요구한다. 계약 후에는 영구 공개 보존이 아니라 정정/삭제 및 과거 브리핑 **표시**에 대한 억제 정책도 필요하다.
- 이미지 규정이 있다고 이미지를 사용해야 한다고 해석하지 않았다. 여행기류는 6필드만 사용한다. 승인 시 메타데이터 전용 활용 가능 여부도 확인해야 한다.
- 연결 보류이며 키/파트너 ID 미보유다. 향후 Secret 이름은 `NEWSWIRE_API_KEY`, `NEWSWIRE_PARTNER_ID`를 제안한다. **이번 코드/워크플로에는 읽는 기능이나 예약 호출이 없다.**

## 구현 및 데이터 품질

신규 연결 출처 **0**, 신규 네트워크 어댑터 **0**이다. 기존 RSS 어댑터·소스 URL·공개 승인 상태는 그대로다. sources.json에는 국내 발행처 국적·매체 유형·원 발표처·공급 경로의 **계측용 메타데이터만** 추가했다.

`src/relevance.py`에 제목의 구체적 대상+변화 조합 5개를 보완했다: 관광업종 가업상속공제, MICE 예산·투자, 의료친화 숙박시설 지정, 한국 연결 항공 공급, 명명 OTA의 B2B/AI 운영 서비스. 일반 상품 출시·할인·여행 팁·지역행사·일반 기업 AI는 제외한다. 기존 Direct/Indirect/Irrelevant 체계와 Indirect 승인 절차는 변경하지 않았다. 태풍 등 인접 산업 원인의 항공 영향은 기존 승인 경로로 넘긴다. 키워드에는 제목에 실제 있는 MICE·가업상속공제·의료친화 숙박시설·탑승률만 사전에 추가했다. 신규 7건 모두 비어 있지 않은 제목 기반 키워드를 갖고, 기존 공개 47건의 키워드는 동일하다. 일반 AI·홍보 단어를 키워드로 만들지 않는다.

7건의 제목 근거를 수동 검토해 모두 관광산업 대상으로 판단했다. 이는 **이 표본의 검토 결과**이며 전체 엔진 정확도 측정이 아니다. public_news_direct_ratio=1.0은 선별된 공개 자료의 구성비이지 모델 precision이 아니다. 기존 일반 기업·행사·프로모션 음성 사례와 영문 키워드 회귀 테스트도 유지한다.

`src/editorial.py`는 의료친화 숙박시설의 명명 국내 도시 및 한국 연결 노선 근거만 추가했다. 국내 언론사라는 사실이나 OTA 이름만으로 한국 우선 등급을 부여하지 않는다. `src/coverage.py`와 Actions 요약 보고에 현재 **권리 게이트를 통과한 뉴스만**의 국내 공급원/신규 기여/7일 발행/매체 유형/6카테고리/Top3/경로·발행처 수를 추가했다. 새 공급원을 연결하지 않은 상황이 운영 KPI에도 그대로 드러난다.
