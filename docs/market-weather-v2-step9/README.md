다운로더·내부 API·새 DB·워크플로·UI는 추가하지 않았습니다.

## 구현과 무결성

- `src/macro/aviation.py`: 기존 `xlsx.workbook`을 재사용합니다. 파일 크기·SHA-256,
  단일 `MENU` 시트, 공식 헤더·단위, 조회 요청 필터, 15개 공항 목록, 국제선·출도착·월별
  조건을 검증합니다. 정수만 허용하며 음수·결측·중복·현재/미래 월·기간 변경·합계 불일치,
  오류 HTML·수식·중복 셀을 차단합니다. 단위나 제공 형식이 바뀌면 새 검토가 필요합니다.
- 시계열 UI는 **연도 범위 × 각 연도에 적용되는 월 범위**입니다. Step 7 원본의
  1~10월 60개월과 11~12월 10개월을 각각 검증한 뒤, 월이 겹치지 않고 연속 70개월인지
  확인합니다. 빠진 월을 0으로 채우지 않습니다. 월별 소계·전체 합계·도착+출발도 검증합니다.
- 공항별 XLSX 두 개는 같은 두 기준월의 합계 대조에만 사용합니다. 추가 관측으로 가산하지
  않으며, 이 대조는 동일 제공기관 내부 대조이지 전국 70개월의 독립 검증이 아닙니다.
- `src/macro/aviation_series.py`: 기존 비공개 `macro_archive.json`의 선택적
  `aviation_indicators`·`aviation_sources` 영역에 저장합니다. KTO·TOURGO 정수 원장과
  ECOS 소수점 원장을 옮기거나 형변환하지 않습니다. 두 계열을 모두 검증한 사본만 반영합니다.
- 원본 파일명·해시·다운로드 URL·조회일·시트/행·집계 정의를 보존합니다. 실제 공표일은
  `null`, 잠정/확정은 `not_stated`이며 수집일로 공표일을 채우지 않습니다.
- 값·도착/출발 또는 출처 빈티지가 바뀌면 정확한 이전/이후 관측과 감지 시점을 정정 이력에
  남기고, 원본 파일 manifest의 이전 배치도 유지합니다. 이전 빈티지로의 되돌림과 같은
  조회시각의 상충 파일은 거절합니다. 반복 입력은 관측·정정·빈티지를 중복 생성하지 않습니다.
- `src/macro/engine.py`: 기존 컬렉터에 명시적 `aviation_bundle` 입력을 연결했습니다.
  자동 다운로드는 없으며 `force`도 비활성 설정을 우회하지 못합니다. 항공만 지정한 비공개
  검증은 공개 `macro.json`·`macro_health.json`을 쓰지 않습니다. 공개 투영은 활성/게시 플래그를
  바꿔도 이 공급원과 자료형을 제외합니다.
- `src/pipeline/validation.py`: 기존 영속 검증에서 항공 영역의 월·계열·정정·빈티지 손실을
  차단하고, 항공 지표가 공개 Macro 결과에 들어가면 거절합니다.

## 검증 자료의 구분

**실제 원본:** `/workspace/work/weather49-step7/`의 파일과 두 manifest를 대조했습니다.
전국 XLSX **4개를 실제 파싱**하여 관측 **140개**와 Decimal 기반 6자리 반올림 YoY
**116개(2022-01~2026-10)**를 Step 7 격리 결과와 대조했습니다.
인천 보조 XLS 2개는 원본 해시·크기를 재검증했으며 이 도구에서 BIFF 값을 다시 파싱하지는
않습니다. Step 7의 인천 독립 대조는 2025-09·2026-09의 인천 성분에 한정됩니다.
나머지 기간 또는 전국 전체의 독립 대조가 끝났다고 표시하지 않습니다.

**합성 테스트:** `tests/test_macro_aviation.py`는 실행 시 만든 작은 XLSX만 사용합니다.
정정·빈티지 보존, 반복 입력, 오류 파일·필터·단위·중복·결측·기간 차단, 공개 배제,
기존 원장과 실패 시 파일 보존을 시험합니다. 합성 정정 시험은 실제 통계 정정 이력의 확보를
뜻하지 않습니다. 실제 원본·관측값·월별 가공 데이터는 Git에 추가하지 않았습니다.

**최신 운영 사본:** 읽기 전용 `data/live` 커밋
`7db0c31a031536ca2d08346418f4592f34d53434`의 격리 사본으로 기존 Macro **621개**,
뉴스·리서치·공개 파일 보존을 확인합니다. 실제 운영 브랜치에 쓰거나 Actions를 실행하지 않습니다.
검증 요약은 `verification.json`에 기록하며 원본/비공개 가공 결과는 외부 격리 경로에 남깁니다.

로컬 재현 명령(명령은 저장소 디렉터리에서 실행):

```sh
python -m unittest discover -s tests -v
python -m tools.validate_aviation_foundation \
  --evidence-dir /workspace/work/weather49-step7 \
  --baseline-root /workspace/work/weather49-step9/live-baseline \
  --work /workspace/work/weather49-step9/new-private-replay
```

`--work`는 저장소·원본·기준 사본 밖의 **새 디렉터리**여야 합니다. 기존 출력에는 덮어쓰지 않습니다.
원본이 없거나 해시가 다르면 실패하며 원본 재현 성공으로 보고하지 않습니다. 도구는 메모리에서만
테스트용 수집 허가를 주입해 엔진 경로를 검증합니다. 이는 실제 권리·운영 승인이 아니고 설정 파일로
저장하지 않습니다. 출력 보고서도 운영 승인·게시를 모두 false로 유지합니다.

## 운영 준비 상태와 남은 조건

공급원 1개와 지표 2개는 모두 `enabled: false`, `publication_status: blocked`입니다.
수집·게시 승인도 각각 false이고 과거 KTO·TOURGO·ECOS 설정은 변경하지 않았습니다.
**즉시 운영 활성화 가능한 신규 항공 계열은 0개**입니다.

다음 근거와 별도 운영 리뷰가 필요합니다.

1. KAC/인천 공동 통계 파일별 재사용·재배포 조건과 필수 출처 표기.
2. 반복 다운로드·자동 수집을 허용하는 공식 경로·범위. 현재 구현에는 자동 다운로드가 없습니다.
3. 과거 정의 개정·소급 정정·잠정/확정 및 빈티지 처리에 대한 제공기관 근거.
4. 독립 교차검증의 인정 범위와 미검증 기간 처리. 현재 상태는 부분 검증입니다.
5. 날짜·대상 기간·근거를 명시한 운영자 **수집 승인**과 별도의 **게시 승인**.

수집 게이트는 위 검토와 날짜/기간 범위가 있는 수집 승인을 요구합니다.
게시 승인만으로 수집이 열리지 않고 수집 승인만으로 공개가 열리지 않습니다.
공개 투영과 자동 수집은 별도 후속 개발·승인 대상입니다. 새 점수·가중치·날씨 등급은 없습니다.
